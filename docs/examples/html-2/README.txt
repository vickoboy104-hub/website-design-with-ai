HTML practical 2: A restaurant menu page

Present real-world menu information with categories and prices.

HOW TO RUN
Open index.html in Edge or Chrome. For VS Code practice, right-click index.html → Open with Live Server.

EXPECTED RESULT
Market Kitchen
Lunch menu
Meal                         Price
Jollof rice                 2500
Vegetable soup          3000
1 Choose a meal.  2 Ask the attendant.

WHAT THE CODE DOES
header, main and footer: Separate the introduction, main content and closing note.
h1, h2 and p: Give the page and sections names, then normal text.
table and caption: Create and name a data table; not a page-layout tool.
tr, th and td: Make a row, heading cell and ordinary data cell.
scope="col": Associates a heading with its column.
ol and li: Make ordered steps and each step.

TRY IT
Add a third meal and its price. Keep each price in the same row as its meal.

CHECK
Two meals and two prices appear.
The ordering instructions are numbered.
