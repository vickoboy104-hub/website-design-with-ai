Make a simple profile page for a student or craft worker.

HOW TO RUN
Open index.html in Edge or Chrome. For VS Code practice, right-click index.html → Open with Live Server.

WHAT THE CODE DOES
main: Contains the main content.
h1 and h2: Name the page and introduce a section.
p: Groups a paragraph of text.
strong and em: Mark importance and emphasis; usually bold and italic.
ul and li: Create an unordered list and its individual items.
