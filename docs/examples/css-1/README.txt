CSS practical 1: A clear business introduction

Style a service heading and short description.

HOW TO RUN
Open index.html in Edge or Chrome. For VS Code practice, right-click index.html → Open with Live Server.

EXPECTED RESULT
Clean Home Services
Careful cleaning for small offices.
Ask a question
Pale background • dark readable text
Large heading • centred content

WHAT THE CODE DOES
body, h1 and a selectors: Choose all matching elements.
.intro: Chooses the element with class="intro".
font-family and font-size: Choose typeface and size; rem follows the root text size.
color and background: Set foreground and background colours.
line-height: Sets comfortable line spacing.
padding, max-width and margin: Add inner space, limit line length and centre the block.
HTML main, h1, p and a: Contain the introduction, heading, sentence and mail link; mailto opens a configured email app.

TRY IT
Change the brand colour in a and compare. Keep text contrast readable.

CHECK
The heading is larger than the paragraph.
Content remains readable when the browser narrows.
