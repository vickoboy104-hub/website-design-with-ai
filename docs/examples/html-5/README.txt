HTML practical 5: A school club home page

Build navigation, a self-contained article and an expandable answer.

HOW TO RUN
Open index.html in Edge or Chrome. For VS Code practice, right-click index.html → Open with Live Server.

EXPECTED RESULT
Bright Readers Club
Home   About
This week
Bring one short story for discussion.
▸ Do I need to buy a book?
Click it: No. Bring a book you already have.

WHAT THE CODE DOES
header, main, h1, h2 and p: Organise the page and its readable content.
nav and aria-label: Identify and name a navigation region.
a and relative href values: Link to files in the same folder.
article: Groups a self-contained club update.
details and summary: Provide an expandable answer with a clickable summary.

TRY IT
Add a Contact link and contact.html. Test the return link to Home.

CHECK
About opens and Home returns.
The question expands without JavaScript.
